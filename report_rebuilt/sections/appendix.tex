\section{Evidence and Manuscript Reconciliation}
The older \texttt{docs/report/report.tex} discusses an incomplete RoBERTa comparison and legacy classical values (including a 0.6282 result). Those values are not mixed with the shared staged cohort. The 71-page English report under \texttt{reports/} already describes the two-stage neural results but says compatible classical results are missing; the current snapshot contains them. The five-page English paper captures the main neural leaders and limitations. This reconstruction uses raw current run evidence whenever prose is stale.

The top-four selection manifest and the fixed five-model final cohort are retained as separate facts. E4's deferred threshold tuning is distinguished from an actually tuned experiment. Exact duplicate grouping is distinguished from near-duplicate removal or project-independent evaluation. File-based operation and in-memory computation are distinguished from interchangeable persistence backends.

An external evidence map is provided in \path{evidence_audit.md}, together with \path{source_inventory.csv}, \path{audit_facts.json}, and \path{implementation_gaps.md}. The inventory records candidate evidence hashes; the evidence map states which sources were substantively inspected, rather than implying every inventoried byte was manually reviewed.
