\begin{abstract}
Class comment sentences can communicate several information types simultaneously. This report evaluates five traditional machine-learning methods and seventeen RoBERTa/CodeBERT configurations for multi-label classification of 6,738 NLBSE'23 sentences in Python, Java, and Pharo. Evidence is reconstructed from source code, fixed split artifacts, 69 completed five-fold screening records (including a majority dummy), and 30 final-evaluation records. Word and character TF-IDF provide competitive Java baselines: logistic regression reaches screening micro-F1 0.5972, compared with 0.5968 for the RoBERTa BCE reference. The reference has larger advantages over the strongest traditional models on Python and Pharo. CodeBERT with R-Drop leads Transformer screening on Python and Java (0.6479 and 0.6225); RoBERTa with focal loss leads Pharo (0.7152). Among the five Transformers evaluated on each final split, the highest test micro-F1 values are 0.6541 for Python (CodeBERT R-Drop), 0.7034 for Java (CodeBERT focal), and 0.7371 for Pharo (RoBERTa BCE). Higher aggregate F1 does not imply improvement on every label. Screening used the entire population before final splitting, and neural checkpoints were selected on the same validation fold later used for scoring. Accordingly, these measurements support an exploratory comparison rather than independent confirmation or a causal attribution to individual model components. The report documents software modules, numerical provenance, execution instructions, and unresolved implementation requirements without inventing missing predictions or experiments.
\end{abstract}
