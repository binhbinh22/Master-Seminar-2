\begin{abstract}
We compare five traditional machine-learning methods and seventeen RoBERTa/CodeBERT configurations for multi-label classification of 6,738 NLBSE'23 comment sentences in Python, Java, and Pharo. Our pipeline combines language-specific binary targets, exact-text-grouped partitions, word/character TF-IDF baselines, and pretrained neural encoders. Logistic regression is competitive with RoBERTa BCE on Java screening micro-F1 (0.5972 versus 0.5968), while the Transformer reference has larger advantages on Python and Pharo. CodeBERT with R-Drop leads neural screening on Python and Java (0.6479 and 0.6225); RoBERTa with focal loss leads Pharo (0.7152). The highest observed final-test micro-F1 values are 0.6541, 0.7034, and 0.7371 for Python, Java, and Pharo, respectively. Label-level analysis shows that higher aggregate F1 can coexist with weaker minority-label detection. Exploratory data analysis and stored learning curves explain the support imbalance and the role of validation-based stopping. We also provide interchangeable dataset storage adapters and reproducible result-generation scripts. Results are interpreted under the evaluation design and limitations stated in Section~\ref{sec:validity}.
\end{abstract}
\noindent\textbf{Keywords:} code comments; multi-label classification; TF-IDF; RoBERTa; CodeBERT; class imbalance.
